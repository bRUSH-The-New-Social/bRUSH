# bRUSH!

## The idea

bRUSH is a social drawing app for making creativity part of the day. Everyone gets the same short prompt, then takes it in their own direction. One person draws a heroic sandwich; another draws a sandwich with stage fright. Both are correct.

When the timer runs out (or you decide your masterpiece is ready), post your drawing and see what your friends made from the very same prompt. Turns out “draw a confused cloud” means something different to everyone.

## The fun part

Friends can award gold, silver, and bronze medals to their favorite drawings, plus participation medals for art that deserves a little extra love. Keep a drawing streak going, check out profiles, and see how you stack up on the leaderboard. Friendly competition encouraged; berets optional.

## Who it’s for

bRUSH is for friends, families, and anyone who wants a low-pressure reason to make something. No art degree required. Stick figures, bold experiments, and drawings that somehow become potatoes are all welcome.

## Why we’re making it

Making things is more fun when you can share the moment. bRUSH gives people a small daily excuse to be creative, see how others think, and cheer each other on. It’s not about getting every line right; it’s about showing up, drawing something, and having a laugh together.

## Features

- Daily drawing prompts generated by a Firebase Cloud Function with Gemini, with fallback prompts if generation fails.
- A timed drawing canvas built with PencilKit.
- A feed for viewing friends’ drawings and awarding medals.
- Friends, friend requests, and a leaderboard.
- User profiles, customizable avatars, drawing statistics, streaks, and share cards.
- Sign in with Apple and Google, plus email and password accounts.

## Technology

- Swift and SwiftUI
- Firebase Authentication, Cloud Firestore, Realtime Database, Cloud Storage, and Cloud Functions
- PencilKit and Apple Authentication Services
- Google Sign-In and Gemini API

## Build the iOS app

1. Open `brush.xcodeproj` in Xcode.
2. Make sure the app target’s bundle identifier matches the Firebase iOS app registered for this build.
3. Add that app’s `GoogleService-Info.plist` to the `App` group and app target. The plist is required for Firebase configuration; don’t commit private credentials or signing keys.
4. Select the `brush` scheme and an iOS simulator or device, then build and run.

Sign in providers and App Check also need to be configured for the matching app in the Firebase console. Sign in with Apple additionally requires the Apple capability and Firebase Apple provider configuration.

## Daily prompt backend

The Firebase Functions source is in `functions/`. It serves the daily prompt from `generateDailyPrompt` and stores the current prompt in Cloud Firestore. The function expects `GEMINI_API_KEY` in its environment.

To install dependencies and build the functions:

```sh
cd functions
npm install
npm run build
```

Deploy from the repository root with the Firebase CLI:

```sh
firebase deploy --only functions
```

## Repository layout
